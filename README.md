# π · Aura

Бесконечная мелодия и светящаяся вода из цифр числа π.

Каждая цифра π превращается в **одну ноту** (пентатоника, две октавы) и **одну каплю света** — кольцо волны в чёрной воде. Цифры генерируются «краником» (spigot) в Web Worker, так что последовательности не существует и конца не видно.

Позиция в π сохраняется между визитами: закрыли вкладку — вернулись и продолжили с того же места.

## Как запустить

```bash
npm install
npm run dev      # разработка
npm run build    # проверка типов + сборка в dist/
npm run preview  # локальный просмотр сборки
npm test         # юнит-тесты (Vitest)
```

Сборка — статическая папка `dist/`, работает без установки и без сети.

## Стек

| Что | Чем |
|---|---|
| Сборка | Vite + TypeScript |
| Графика | WebGL2 напрямую (без three.js): один полноэкранный прямоугольник + fragment shader |
| Звук | Web Audio API: ноты, дрон и реверберация генерируются кодом, аудиофайлов нет |
| Цифры π | Web Worker + алгоритм Гиббонса (spigot) |
| Языки | свой мини-модуль i18n: `uk` и `en` |

Без фреймворков, без CDN, без аналитики, без трекеров.

## Возможности

- **Два языка** — украинский и английский, переключаются мгновенно в меню. Первый запуск определяет язык по браузеру, выбор запоминается.
- **Пентатоника** — мажорная (по умолчанию) или минорная. Двойная цифра звучит громче и на октаву выше.
- **Точка Фейнмана** — на 762-й цифре после запятой начинаются шесть девяток подряд: вода становится зеркальной, звучит долгий светлый аккорд.
- **Жесты** — касание добавляет каплю-ноту (высота зависит от X), свайп меняет скорость, долгое удержание замораживает воду и играет последние десять цифр арпеджио, наклон телефона сдвигает блики.
- **Клавиатура** — `Space` пауза, `M` меню, `←`/`→` скорость, `Esc` закрыть.
- **«Сохранить момент»** — кадр с подписью «π · цифра N» в PNG, с нативным «Поделиться» на мобильных.
- **PWA** — работает офлайн после первой загрузки, `manifest.webmanifest` и иконки 192/512.

## Структура

```
src/
├─ main.ts          точка входа: связывает π, звук, графику и UI
├─ pi/              spigot, воркер, буфер цифр, точка Фейнмана
├─ audio/           движок, голоса-капли, дрон, реверберация, гаммы
├─ gfx/             WebGL2-рендерер, шейдер воды, кольца, палитра цифр
├─ ui/              стеклянное меню, HUD, жесты, сохранение кадра
└─ i18n/            uk.json, en.json
```

## Проверки

Помимо юнит-тестов (`tests/`) есть живые сценарии в `scripts/`, которые гоняют приложение в браузере через CDP:

```bash
node scripts/smoke.mjs     # базовая проверка загрузки
node scripts/interact.mjs   # меню, язык, жесты, «Начать сначала»
node scripts/feynman.mjs   # точка Фейнмана
node scripts/audio.mjs     # жизненный цикл AudioContext и голосов
node scripts/save.mjs      # сохранение кадра в PNG
node scripts/soak.mjs      # длительный прогон: утечки и стабильность
```

Сценариям нужен запущенный `npm run preview` и Chrome с `--remote-debugging-port=9222`.
